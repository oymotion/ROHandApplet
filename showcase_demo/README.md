# AP002 Showcase Demo

独立 AP002 左手演示程序。旧 Demo 不需要修改，本目录复制并封装需要的手势、压力、URDF 显示逻辑。

## 功能

- 自动识别 RS485 串口，也支持 `--port COMx` 手动指定。
- 左上显示 AP002 左手 URDF，使用 PyBullet 渲染后嵌入 Qt。
- 左下显示 AP002 左手压力图。
- 右侧显示时间轴力向量：
  - 横轴为时间。
  - 纵轴为五根手指。
  - 每个 3D 力点绘制一个箭头。
  - 箭头方向使用实时 `direction`。
  - 箭头长度使用 `tangential`。
  - 箭头颜色和点大小使用 `normal`。
- 保留摄像头手势控制实体手。
- 记录目标关节、实际关节、压力数据。
- 支持 `.jsonl` 记录、`.jsonl` 回放、`.csv` 导出。
